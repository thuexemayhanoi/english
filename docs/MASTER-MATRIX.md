## Subclusters and representative intents

### 1. Hanoi motorbike rental (90)

## Overlap / cannibalization controls

Detected risk pairs and how the matrix separates them (applied at row level when the full matrix is built):

1. "Renting a motorbike in Hanoi" (cluster 1 overview) vs "Hanoi motorbike rental" location pages → area guides must add unique local context; only one canonical rental hub page.
2. Scooter model review (3.1) vs scooter comparison including that model (3.2) vs "best scooter for X" (3.3) → comparison targets decision intent, review targets the model entity; cross-linked, not duplicated.
3. 50cc legal rules (6.2) vs licence classes (11.1) → 6.2 is a summary with canonical link to the full legal article in cluster 11.
4. Electric registration (7.4) vs licence/registration cluster (11.5) → same rule, single canonical legal article.
5. Clutch maintenance (5.4) vs general maintenance (8.x) → 5.4 covers rider-facing awareness only; procedures live in cluster 8.
6. Trip route guide (13.1) vs destination travel guide (12.3/14.x) → route = logistics/how to get there; destination = what to do.
7. Helmet buying guide (9.1) vs helmet law (11.3) → product guidance vs legal requirement, cross-linked.
8. No doorway/location-spin pages: district guides only where ≥10 genuinely distinct intents exist; no "rent a motorbike in [neighbourhood]" spins.

Near-duplicate scan rules (per batch): slug similarity check, intent statement must differ, H1 must differ, no two articles answering the same question with the same scope.
