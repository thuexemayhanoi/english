# SOURCE MAP v3 — English Motorbike Knowledge Hub

## Source precedence (absolute rule)

FIRST-PARTY DATA (OWNER-FACTS, owner-history intents, GSC evidence) > PRIMARY/OFFICIAL SOURCE (government law, vietnam.travel, official docs) > MANUFACTURER (Honda VN, Yamaha VN, VinFast, SYM, Suzuki, Piaggio) > SPECIALIST PUBLICATION > COMMERCIAL WEBSITE > FORUM.

Competitor websites are for discovery, not truth. Truth is never decided by majority vote.

## Reliability classes

A+ first-party owner data · A authoritative/primary · B specialist publication · C commercial reference · D forum/inspiration only.

## Known data limitations (recorded, not blockers)

1. Full 6–12 month GSC CSV not supplied. Provisional matrix uses the 2026-08-18→2026-09-16 SiteGuru/GSC snapshot, historical audit evidence ("motorbike rental hanoi") and owner history. Refine later if a full export arrives.
2. Customer questions provided as recurring themes from owner history, not verbatim quotes. Stored as source_type=owner-history. Never quoted as customer speech in articles.
3. Fleet availability per model unconfirmed — all model availability wording defers to contact.

## Sources

FIRST-PARTY (A+): docs/OWNER-FACTS.md (absolute priority for business claims; nothing external overrides it) · owner-history intent themes (54) · GSC snapshot (see docs/CUSTOMER-INTENTS.md).

MANUFACTURER (A, for specs): hondavn.com.vn · yamaha-motor.com.vn · vinfastauto.com (range published with test conditions; always note real-world range varies with speed, temperature, terrain, load) · SYM/Suzuki/Piaggio VN (when added). Manufacturer page beats retailer beats classifieds beats forum — always.

GOVERNMENT/LEGAL (A, for law): Law on Road Traffic Order and Safety + decrees via chinhphu.vn / vanban.chinhphu.vn / Ministry of Public Security documents. Track 2026+ changes from official documents, not summary blogs. thuvienphapluat.vn (B) and mva.vn (C) secondary only.

OFFICIAL TOURISM (A): vietnam.travel (Vietnam National Authority of Tourism) — destinations, Hanoi, Northern destinations, transport, weather, safety, itineraries. insightguides.com (B) background.

TECHNICAL/SERVICE (A when available): manufacturer owner's manuals / official service data. Torque, oil, pressure, voltage, interval values NEVER from forums/shop sites/Scribd (D — discovery only: 2banh.vn, hocngheoto.edu.vn, thietbithaovoxe.com, Scribd textbook).

SEO/CODE DOCS (A): Google Search Central · schema.org · jekyllrb.com docs · docs.github.com (GitHub Pages). Implementation follows official docs, never SEO-blog recipes.

COMPETITOR/COMMERCIAL (C/D, discovery only): hanoimotorbikerental.com · riderly.com · rentalmotorbikehanoi.com · motogo.vn (card UX field inspiration only — original design) · travelguidevietnam.net · travelhanoi.com.vn · travelhanoi.org · govietnamtrip.com (route facts need independent verification) · chobaoho.vn · gsports.vn · xedienvietthanh.com · xebaonam.com · autopro.com.vn (news structure example; date-checked).

## Research-verification flags

R1 legal (government text, last_reviewed) · R2 travel/route verification · R3 manufacturer specs · R4 business facts (OWNER-FACTS only) · R5 technical service data (manufacturer documentation only).
